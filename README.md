# Spring Boot REST API

API REST desenvolvida em Java com Spring Boot como projeto de estudo e prática de desenvolvimento backend.

O projeto está sendo desenvolvido durante meus estudos de Spring Boot, acompanhando um instrutor e aplicando os conceitos na prática.

## Tecnologias

* Java -25
* Spring Boot -4.1.0
* Spring Data JPA
* MySQL -8.0.46
* Maven
* Bean Validation
* REST API
* Postman

## Objetivo

Praticar o desenvolvimento de aplicações backend utilizando Spring Boot, incluindo criação de APIs REST, persistência de dados, validação e integração com banco de dados.

## Status

Em desenvolvimento.

O projeto continua sendo utilizado como ambiente de estudo para testar e aprofundar conceitos de desenvolvimento backend com Java e Spring Boot.
